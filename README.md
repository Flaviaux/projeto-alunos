# Diário de Turma

Projeto simples em HTML e CSS (sem JavaScript) para praticar e subir no GitHub.

## Como usar
1. Baixe a pasta e abra `index.html` no navegador.
2. Troque "seu nome aqui" no `index.html` pelo seu nome.
3. Mude as cores no começo do `style.css` (bloco `:root`).

## Desafios
- Adicionar mais alunos na tabela
- Criar uma página `sobre.html` e linkar no menu
- Mudar a paleta de cores
- Publicar no GitHub Pages
